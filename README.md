## EX01 - Selectors

Neste exercício foi aplicada uma folha de estilos CSS a uma página HTML já existente.

Foram utilizados diferentes tipos de seletores: seletores de elemento, classe, ID, descendentes, atributos e pseudo-classes.

Também foram utilizados os estados `hover` e `focus` para alterar alguns elementos quando o utilizador interage com eles.

## EX02 - Box Model

Neste exercício foi criada uma coleção de cartões para demonstrar o funcionamento do Box Model.

Foram utilizadas as propriedades `width`, `padding`, `border`, `margin` e `box-sizing`.

Também foi criada uma comparação visual entre `content-box` e `border-box` para perceber a diferença no cálculo das dimensões dos elementos.

## EX03 - Typography

Neste exercício foi criada uma página de documentação técnica com diferentes estilos de tipografia.

Foram utilizadas propriedades como `font-family`, `font-size`, `line-height`, `font-weight`, `color` e `background`.

Também foram utilizados diferentes estilos para títulos e links.

Como funcionalidade adicional, foram criadas variáveis CSS utilizando `:root` e `var()` para reutilizar as cores da página.

## EX04 - Components

Neste exercício foram criados vários componentes visuais reutilizáveis utilizando CSS.

Foram criados:

- Cards
- Buttons
- Alerts
- Badges
- Forms

Os componentes utilizam classes base e classes adicionais para criar diferentes variantes mantendo um estilo consistente.

Não foram utilizados frameworks CSS como Bootstrap ou Tailwind.

## EX05 - Flexbox Playground

Neste exercício foram criados cinco layouts diferentes utilizando Flexbox.

Foram utilizadas propriedades como:

- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`
- `gap`
- `flex-grow`
- `flex-shrink`

Também foi criada uma barra de navegação utilizando Flexbox.

## EX06 - Navigation Bar

Neste exercício foi criada uma barra de navegação responsiva.

A barra contém um logo, vários links e um botão.

Foi utilizado Flexbox para organizar e alinhar os elementos.

Também foi utilizada uma media query para adaptar a navegação a ecrãs mais pequenos.

## EX07 - Photo Gallery

Neste exercício foi criada uma galeria de fotografias utilizando CSS Grid.

A galeria utiliza múltiplas colunas, `gap` e imagens responsivas.

Também foram utilizados diferentes tamanhos para as fotografias.

Como funcionalidade adicional, foram utilizadas Grid Areas para definir a posição das imagens dentro da galeria.

## EX08 - Dashboard

Neste exercício foi criado um dashboard utilizando CSS Grid como estrutura principal.

O dashboard contém:

- Header
- Sidebar
- Main
- Cards
- Table
- Footer

Foram utilizadas Grid Areas para definir a posição das diferentes partes da página.

Também foram adicionadas media queries para adaptar o dashboard a dispositivos com diferentes larguras.

## EX09 - Responsive Challenge

Neste exercício foi criada uma landing page utilizando uma abordagem Mobile First.

A página foi preparada para funcionar corretamente em diferentes tamanhos de ecrã, incluindo:

- 320px
- 768px
- 1024px
- 1440px

Foram utilizadas media queries com `min-width` para adaptar progressivamente o layout a ecrãs maiores.

Também foram utilizadas imagens responsivas, Flexbox, Grid e `box-sizing` para evitar scroll horizontal.

Como funcionalidade adicional, foi implementado um modo escuro utilizando `prefers-color-scheme: dark`.
